Workout Program Library Log + Settings
  • Compact rows stay production-quiet: 23 px numbered check, one-line name, mono prescription, one truncating log line. Done rows fade; nothing grows.
  • Row tap expands “last time” in place — two switchable options above: Flat (two visits as plain lines + text actions) or Chips (last session as tactile set chips, note, one Log sets button, quiet links).
  • The fill sheet is a live set table (Hevy/Strong pattern): number chip · previous ghost · weight well · reps well · check. The number chip carries set type — tap cycles 1 → W → D → F.
  • A completed set washes its whole row green and starts the rest pill; Skip dismisses it. Numbers are tabular mono so nothing reflows.
  • Drop chain is one tonal card: chip flow, reason pills, a − / + stepper for the next weight. Same parts, same units, no new vocabulary.
  • kg / s / BW appear only on actual values, never on the prescription. Per-side sets get one small L/R switch in the previous column.
